=========================================
ชื่อโปรเจกต์ (Project Name)
=========================================
CVRP Solver (routeoptimization_version4.py)
โปรแกรมสำหรับหาเส้นทางการขนส่งที่ดีที่สุด (Capacitated Vehicle Routing Problem) 
โดยใช้อัลกอริทึมต่างๆ เช่น Nearest Neighbor, Clarke-Wright Savings, Sweep Algorithm 
พร้อมทำ Local Search Optimization และ Perturbation


ข้อกำหนดระบบ (Prerequisites)
-----------------------------------------
- Python 3.x หรือสามารถรันบน Google Colab ได้โดยตรง


Library / Dependencies ที่ใช้ในโปรแกรม
-----------------------------------------
1. Python Standard Library (มาพร้อมกับ Python ไม่ต้องติดตั้งเพิ่ม):
   - math, re, os, sys, random, time, collections
2. Third-party Library (ต้องติดตั้งเพิ่ม):
   - pandas (ใช้งานจัดการโครงสร้างข้อมูล)


วิธีการติดตั้ง (สำหรับรันบนเครื่องคอมพิวเตอร์)
-----------------------------------------
1. ติดตั้ง Python ให้เรียบร้อย
2. ติดตั้ง Library ที่จำเป็นโดยเปิด Terminal / Command Prompt แล้วพิมพ์:
   pip install pandas


วิธีการรันโปรแกรม (How to run)
-----------------------------------------
** ทางเลือกที่ 1: การรันบนเครื่องคอมพิวเตอร์ผ่าน VS Code (ง่ายที่สุด) **
1. เปิดโปรแกรม Visual Studio Code (VS Code)
2. ไปที่เมนู File -> Open Folder... แล้วเลือกโฟลเดอร์โปรเจกต์นี้
3. นำไฟล์นามสกุล .vrp (ไฟล์ Dataset) มาวางในโฟลเดอร์เดียวกัน
4. ดับเบิลคลิกเปิดไฟล์ routeoptimization_version4.py
5. กดปุ่ม Run (สัญลักษณ์สามเหลี่ยม ▶) ที่มุมขวาบนของหน้าจอ
   หรือคลิกขวาที่โค้ดแล้วเลือก "Run Python File in Terminal"
6. โปรแกรมจะค้นหาไฟล์นามสกุล .vrp ในโฟลเดอร์มาทำงานให้โดยอัตโนมัติ 
   และแสดงผลลัพธ์ในแถบ Terminal ด้านล่าง

** ทางเลือกที่ 2: การรันบน Google Colab (ไม่ต้องติดตั้งโปรแกรม) **
1. เปิดเว็บไซต์ Google Colab (https://colab.research.google.com/)
2. สร้าง Notebook ใหม่ (New Notebook)
3. คัดลอกโค้ดทั้งหมดจากไฟล์ routeoptimization_version4.py ไปวางในเซลล์ (Cell)
4. กดปุ่ม Play เพื่อรันโค้ด
5. โปรแกรมจะแสดงข้อความว่า "กรุณาเลือกไฟล์ .vrp จากเครื่องของคุณ" ให้กดปุ่ม `Choose Files` 
   แล้วเลือกไฟล์นามสกุล .vrp จากคอมพิวเตอร์ของคุณเพื่อเริ่มการคำนวณ


Parameters และ Random Seed ที่ใช้
-----------------------------------------
- Random Seed: 42 (ถูกกำหนดไว้ในบรรทัดที่ 30: random.seed(42))
- Parameters ภายในโค้ด:
  - TIME_LIMIT = 120 (วินาที - โปรแกรมจะหยุดค้นหาหากเกินเวลาที่กำหนด)
  - PERTURB_ITER = 50 (จำนวนรอบการทำ Perturbation เพื่อหลุดจาก Local Optima)


Routes (สำหรับ Web API)
-----------------------------------------
- (ไม่มี เนื่องจากเป็นโปรแกรมสำหรับรันหาคำตอบ ไม่ใช่ระบบ Web API)


ผลลัพธ์ที่คาดหวัง (Expected Results)
-----------------------------------------
เมื่อรันสำเร็จ โปรแกรมจะแสดงผลลัพธ์ใน Terminal / Console ดังนี้:
1. สรุปข้อมูลที่อ่านได้จากไฟล์ .vrp (จำนวนลูกค้า, ความจุ, จำนวนรถ, Demand รวม)
2. กระบวนการหาเส้นทางด้วยวิธีต่างๆ (NN, Multi-start, Clarke-Wright, Sweep, Exhaustive, Perturbation)
3. ท้ายสุดจะแสดงผลระยะทางสั้นที่สุดที่หาได้ พร้อมรายละเอียดว่าได้ผลลัพธ์นั้นมาจากวิธีใด
ซึ่งผลลัพธ์ที่แสดงจะตรงกับภาพหลักฐานที่แนบไป
